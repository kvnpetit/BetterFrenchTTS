BetterFrenchTts

class BetterFrenchTts(source)

High-level French TTS wrapper around Android's native TextToSpeech.

Selects a French voice and compiles a Kotlin DSL to native Android speech operations. Native playback and strict offline voice selection are the defaults. SSML is opt-in.

Quick start

val tts = BetterFrenchTts(context, BetterFrenchTts.Config(
    onReady = { it.speak("Bonjour le monde !") }
))

DSL usage

tts.speak {
    text("Bonjour.")
    pause(500)
    slow { text("Ceci est important.") }
}
