# Module better-french-tts

French text-to-speech tools for Android 8.0 (API 26) and later.
Start with [BetterFrenchTts](io.github.kvnpetit.betterfrenchtts.BetterFrenchTts)
for initialization, voice selection, native playback, queues and file synthesis.
The library uses the installed Android TTS engine: voice quality, pronunciation
and supported controls depend on that engine and its installed voice data.
